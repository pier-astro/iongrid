# Inspect a spectral table

Open `inspect_tables.ipynb` with the `inspect` extra installed. The notebook
generates a synthetic iongrid point table and its OGIP transmission table.
The sliders select stored spectra. To inspect your own results, replace the
paths with a packed iongrid FITS table or an OGIP model.

See the [output schema](../../docs/schema.md) for quantities and units.
