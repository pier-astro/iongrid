# CLOUDY output and resolution choices

The supplied input template keeps the continuum calculation relatively coarse while exporting line absorption from CLOUDY's separate fine mesh. This avoids making every opacity and rate calculation run at line-profile resolution. The exact number and spacing of coarse cells depend on the CLOUDY version and its `continuum_mesh.ini`; `set continuum resolution 4` multiplies the coarse cell widths by four relative to that installation's default. It is **not** a fixed resolving power of four. This factor is part of the chosen production setup, not a property of the saved spectral files. See the [CLOUDY C24 HAZY manual, continuum resolution](https://cloudy.musesframework.io/workshop/24Tokyo/hazy1_Tokyo24.pdf).

| Output | Spectral contents used here | Native sampling and microturbulence |
| --- | --- | --- |
| `.con` | Incident and transmitted radiation; outward and reflected diffuse continuum components. Emission lines are suppressed in saved continua by `set save line width suppress`. | **Coarse continuum mesh**, affected by `set continuum resolution 4`. CLOUDY's gas solution depends on the `turbulence` command, but the extracted diffuse continuum has no resolved turbulent line profile. The coarse transmitted spectrum is kept as a diagnostic, not used to reconstruct narrow absorption. |
| `.raw` | Reflected incident and reflected diffuse components used to isolate the slab's diffuse continuum. | **Coarse continuum mesh**, same resolution choice as `.con`. No independent resolved line profile is used from this file. |
| `.opt` | Total, absorption and scattering **continuum** optical depths; the compiler reads absorption and scattering separately. | **Coarse continuum mesh**. It does not supply resolved line optical-depth profiles. Scattering remains a separate, smooth component. |
| `.fopt` | **Line-only** fine optical depth; added to `.opt` absorption depth. No continuum or scattering depth. | CLOUDY's **fine line mesh**, requested only over **0.05–15 keV**. Its internal resolution is designed for line overlap and responds to thermal and turbulent widths. The save command coadds **10 neighboring fine cells by default**, so the output spacing is coarser than the internal mesh; it is not a universal fixed km/s resolution. |
| `.lin` | Emergent, integrated emission-line intensities; no continuum or scattering component. | A **catalogue of discrete transitions**, not a sampled or broadened spectrum. `turbulence` can change the CLOUDY line formation and intensities, but the exported entry does not encode a resolved line profile. |
| `.llab` | Labels and wavelengths used to validate the `.lin` transitions. | Discrete transition metadata; no spectral mesh or profile. |
| `.ovr` | Mean electron temperature used in point metadata. | Spatial/zone diagnostics, not an energy spectrum. |
| `.spc` | Species abundances retained for inspection; not read by the present compiler. | Spatial/species diagnostics, not an energy spectrum. |
| `.out` | Successful-exit check and execution time for manifest refresh. | Run log, not an energy spectrum. |

CLOUDY's [fine optical-depth description](https://cloudy.musesframework.io/workshop/24Tokyo/hazy1_Tokyo24.pdf) explicitly separates the fine line array from the coarse continuum and says that the fine array contains lines alone. Its [turbulence description](https://cloudy.musesframework.io/workshop/24Tokyo/hazy1_Tokyo24.pdf) states that turbulence enters line widths, shielding and pumping. The [saved-continuum description](https://cloudy.musesframework.io/workshop/24Tokyo/hazy1_Tokyo24.pdf) explains that `set save line width suppress` excludes emission lines from saved continua; it does not remove the separately saved line catalogue. These are the reasons the final absorption spectrum is assembled from `.opt` plus `.fopt`, while diffuse emission is assembled from continuum components plus `.lin`.

The compiler uses the reflected diffuse fraction `ConEmitReflec / (ConRefIncid + ConEmitReflec)` from `.raw` to select the diffuse share of `.con`'s reflected component. It adds this to the outward diffuse continuum. It validates `.lin` entries against `.llab`, places them at their line energies, and broadens them numerically. A 16,000-point intermediate log-energy grid from 0.0008 to 102 keV carries the line placement and smoothing. The output grid allocates 7,500 points to 0.05–15 keV, with coarser UV and hard-X-ray extensions to 0.001 and 100 keV. Emission is then converted to bin-integrated photon flux at 10 kpc. The input deck's `radius 16` supplies the reference inner radius unless the run changes it.

## Why the products are assembled this way

The predecessor high-resolution CLOUDY workflow compared the fast-run products with fine-continuum and high-resolution reference runs. Its absorption check found that `exp(-tau_line)` from `.fopt` reproduced the fine-continuum transmission and that combining `.opt` continuum depth, `.opt` scattering depth and `.fopt` line depth reproduced the reference transmission. This is why the line optical depth is taken from `.fopt`: its physical microturbulent width is already present in CLOUDY's line calculation. The coarse `.con` transmission is retained for diagnostics, not used as the high-resolution absorption input.

The emission checks addressed a different output convention. `.lin` reports integrated line intensities but no resolved profile, even though `turbulence` influences the underlying line formation. The predecessor workflow matched the integrated line budget and rebinned slab emission against reference outputs after validating `.lin` entries with `.llab` and broadening those entries externally. It also checked the diffuse-continuum split from suppressed `.con` and `.raw`; directly using `.con`'s reflected component would include reflected incident light. These comparisons motivated keeping the line catalogue separate from the continuum rather than relying on unresolved line spikes in `save continuum`.

The current `compile_node` implementation retains an additional processing step from the prototype: on its intermediate log-energy grid it applies a Gaussian with `sigma_lnE = vturb / (sqrt(2) c)` to the assembled absorption depth, the diffuse continuum and the deposited emission lines before bin averaging. The smooth scattering depth is left as supplied by `.opt`. This numerical step is separate from CLOUDY's native treatment in `.fopt` and from the physical line formation already reflected in `.lin` intensities; it is recorded here so the exact behaviour of existing tables remains reproducible. The predecessor validation established the choice of input products and external emission-line reconstruction; it should not be read as a separate quantitative test of every later packing operation. Changes to this established processing path need a comparison using the spectra and fits for which it was selected.

The input template also requests extended H-like and He-like Lyman levels for line coverage and limits verbose line printing with `print line faint -2`. These choices affect runtime and line completeness. The saved resolution and the output of `set continuum resolution 4` can vary with CLOUDY version and its mesh data, so the actual run setup should stay beside the generated products.
